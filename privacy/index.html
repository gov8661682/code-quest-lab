Privacy

Local by design, transparent about the boundary.

This page describes the current product design. It is not a substitute for the owner-approved legal privacy policy, store disclosures, or hosting-provider terms.

What the game stores

Profiles, class choice, progression, inventory, equipment, settings, achievements, and interrupted-run recovery data are stored locally in browser or native storage. A profile can be deleted from Manage Data.

What normal play does not need

No account, login, email address, real name, classroom identity, chat, social profile, camera, microphone, precise location, contacts, advertising ID, or cloud save is required for core play.

Network boundary

The web shell may be downloaded from the project host and cached for offline play. The game does not intentionally send save data to a server or open external websites during gameplay. The native shells do not need external network access for the core game.

Infrastructure logs

A hosting or CDN provider may create ordinary request logs. Retention, fields, and legal treatment must be confirmed by the project owner before store or school distribution. The product must not claim zero data collection until that review is complete.

Release review still required

  • Approve the public privacy-policy text and support contact.
  • Review Apple App Privacy and Google Play Data Safety declarations against the final native dependencies.
  • Review the generated Android permission set, including the default Capacitor INTERNET declaration.
  • Confirm hosting/CDN retention and any school deployment consent or filtering requirements.

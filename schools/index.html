School review

Information for transparent allowlisting.

Schools and network administrators can review the product boundary before deciding whether to permit code-quest-lab.gov8661682.com. The project does not use proxying, URL masking, domain rotation, tunnelling, or any method intended to bypass security controls.

If access is blocked, use the school's legitimate review or whitelisting process. The project will not attempt to circumvent the control.

Domain and delivery

  • Primary domain: code-quest-lab.gov8661682.com
  • Transport: HTTPS on the published domain.
  • Hosting plan: static web delivery through Cloudflare Pages; the owner must confirm final deployment and log retention.
  • App shell: one first-party HTML/JS game, local SVG assets, manifest, and service worker.

Normal network behaviour

  • The browser downloads the game shell and assets from the same origin.
  • After caching, core play is designed to work without an active connection.
  • No external scripts, ad networks, trackers, chat, social widgets, or user-generated content are required.
  • No external website opens during normal play.

Data and permissions

  • No login, email, real name, classroom identity, or cloud save is required.
  • Progress is stored locally in browser storage.
  • The game does not request camera, microphone, location, contacts, or background tracking.
  • Infrastructure request logs remain a hosting-provider review item.

Support

Get back to the adventure safely.

Code Quest Lab is designed to pause, save, and recover locally. Use the checks below before reporting a problem.

For web play

  1. Use a current Safari, Chrome, Edge, or Firefox release where your school or family permits it.
  2. Open the site once while connected so the app shell can finish caching.
  3. Use the in-game Pause control before closing the tab when possible.
  4. If a profile or checkpoint is missing, do not clear site data; contact support first.

For touch play

  • Use landscape orientation on a tablet or phone.
  • Keep both virtual movement controls clear of your thumbs.
  • Audio is optional; the game should remain playable when muted.
  • On a managed device, ask the administrator to review the domain rather than trying to bypass a block.

Before you write

Please include the platform, browser or app version, device class, approximate time, and the visible error. Do not send passwords, account credentials, student names, save files, or other personal information.

Contact the project

Data and purchase support

The current public build has no live purchase flow. A future one-time unlock will use platform billing and a parent gate; it will not require a browser payment shortcut. If a later store build reports a purchase issue, use the platform's official receipt and refund process as well as the project contact.
